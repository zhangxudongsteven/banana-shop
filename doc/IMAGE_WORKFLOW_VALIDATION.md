# 图像创作优化验证

对应版本：`0.8.0`（2026-09-22）。

## 复现入口

- `corepack pnpm test`：Vitest + React Testing Library，模拟生成动作与 Tale SDK。
- `corepack pnpm test:ui`：仅绑定 `127.0.0.1:4173` 的独立组件预览。复用真实创作页、上传器、结果面板、主题、语言及历史组件；生成、历史和路由由测试替身提供，不连接真实账号或模型。该页面不属于 Next.js 应用路由，也不会随生产构建发布。
- `corepack pnpm lint`、`corepack pnpm build`、`git diff --check`：类型、生产构建与变更检查。

预览页可以载入仓库示例图、切换创作模式/主题/语言、模拟一次失败。生成成功仅返回仓库示例图，不代表模型生成质量验证。

## 自动化覆盖

- 文生图、预设风格结果进入自定义改图；历史 URL 载入、失败保留当前输入和重试。
- 生成期间锁定输入及复用入口，重复提交只执行一次；失败保留上次结果，比较原图绑定提交时快照。
- 可访问上传入口、同一文件再次选择、禁用拖拽、文件类型/大小/合计大小/解码校验。
- 远程下载转换为 Blob，使用实际 MIME 类型扩展名；失败不会触发空下载。
- 保存中/失败时刷新仍保留结果；刷新与完成并发合并去重；刷新发现的任务 ID 在迟到的失败响应或传输异常后仍用于续传；传输失败退出保存中。
- SDK 部分上传失败等待全部请求结束；按同一 taskId 补传，校验归属，创建结果不确定时按 requestId 核对而不盲目重建。
- 视频下线、旧视频 API 返回 410、历史跨页过滤视频且不获取其下载链接；非空蒙版在 REST/Server Action 明确报错且不调用 provider/保存历史。

## 验证边界

- 未使用真实账号登录、调用付费模型或写入真实 Tale 数据；这些链路由 SDK/动作替身验证，尚未完成真实服务验收。
- 内置浏览器两次等待文件下载事件均超时，因此不宣称已验证文件落盘。下载逻辑的响应校验、Blob 转换、文件名、点击和释放由自动化测试覆盖。
- 历史待保存载荷只保留在当前会话；硬刷新、关闭页面前应下载未保存结果。SDK 不提供原子幂等，本轮不承诺跨实例严格只写入一次。
